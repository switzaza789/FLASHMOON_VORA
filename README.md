# Flashmoon Vora Demo/Testnet

Interactive static demo for exploring a binary tree marketing-plan flow. It uses simulated 100 USDT purchases only; there is no wallet, payment gateway, blockchain, or real-money transfer.

## Run locally

From this folder, run any static server, for example:

```text
npx serve dist
```

Then open the local URL. Use **Demo User** or **Demo Admin** to enter quickly, or create a new member from the empty state. The demo persists in browser localStorage and can be reset from the sidebar.

The 40% rebirth rule is intentionally disabled until the formula and placement behavior are confirmed.
